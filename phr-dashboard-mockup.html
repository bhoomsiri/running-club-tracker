  • Sidebar: โชว์ข้อความเต็มเป็นค่าเริ่มต้น · ย่อ/ขยายได้ทั้ง เดสก์ท็อป (☰ พับเป็นไอคอน) และ มือถือ (☰ บน topbar เปิด drawer + backdrop)
  • ส่งผลวิ่ง = ปุ่ม primary ทั้งในเมนู และ ปุ่ม CTA บนหน้า dashboard (มุมขวาหัวข้อ "ภาพรวม")
  • ข่าวประชาสัมพันธ์: เป็น tab ในเมนู + banner ล่างสุดของ dashboard — ออกแบบ 2 แบบ: มีรูป / ไม่มีรูป (รองรับฟีเจอร์ "ข่าวใส่ภาพ" ที่ยัง deferred — ถ้ายังไม่มีรูปใช้ layout แบบไม่มีรูปอัตโนมัติ)
  • เมนูแอดมินแยกหน้า: sidebar สมาชิกมี 6 อัน + ลิงก์ "แอดมิน ›" (เฉพาะแอดมิน) ไป /admin ที่มี layout/เมนูของตัวเอง — ไม่ปนเมนูแอดมินในหน้าสมาชิก
  • รูปโปรไฟล์: mockup ใช้อักษรย่อ — production ดึง image_url จาก Clerk (sync ผ่าน webhook) fallback อักษรย่อ (§11)
  • กราฟ ผูกข้อมูล run ต่อวันจริง (วันพัก = แถบประ ไม่ใช่ 0) · ป้ายช่วง activity="ทั้งหมด" benchmark=แคมเปญ · แคลอรี่/ก้าว "N ใน M"
  • น้ำหนัก/BMI: band กลางๆ ไม่มี "พบแพทย์" · reuse lib/bmi.ts · เจ้าตัวเห็นเสมอ (consent A)
